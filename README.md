# Atlas de Data Science

Aplicación web que explica los conceptos de la ciencia de datos mediante visualizaciones interactivas y animadas, desde los fundamentos matemáticos hasta el aprendizaje automático, las series temporales y la inferencia causal.

## Ejecución local

Requiere Node.js 24 o posterior.

```bash
npm install
npm run dev
```

## Scripts principales

| Script             | Acción                                      |
| ------------------ | ------------------------------------------- |
| `npm run dev`      | Servidor de desarrollo                      |
| `npm run build`    | Build de producción en `dist/`              |
| `npm run check`    | Lint, tipos, tipografía y pruebas unitarias |
| `npm run test:e2e` | Pruebas de extremo a extremo                |
